# automation/skills

These are **project-local skill source files** — documentation that captures
house conventions for the research pipeline. They are not auto-loaded; they are
sources you edit here and then install into your Computer skill library.

To install a skill into your Computer skill library, use `save_custom_skill`.

## Skills

- **[financial-metric-prioritization](financial-metric-prioritization/SKILL.md)**
  — canonical metric priority and source-of-truth hierarchy for buy-side equity
  research: GAAP vs non-GAAP rules, the SaaS metric order (revenue > gross profit
  > operating income > FCF > net income), NTM vs LTM labeling, the
  filing/provider source hierarchies, and prompt + provenance patterns. Use when
  drafting drilldowns, briefings, valuation memos, or any artifact citing
  financial metrics for a public company.
